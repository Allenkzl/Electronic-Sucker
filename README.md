# 电子吸盘浏览器控制器

用网页上的「吸取 / 放下」两个按钮，通过 Arduino Uno 控制电子吸盘和电磁阀。

> 📘 完整的运行逻辑、分层设计、协议说明、设计决策与缺陷记录见 **[Project.md](Project.md)**。
> 本文档只讲怎么装、怎么用。

```
浏览器网页 (http://127.0.0.1:8787)
      │  HTTP + SSE 实时推送
      ▼
Python 桥接服务 (bridge/bridge.py)      仅需标准库 + pyserial
      │  串口 115200，文本行协议
      ▼
Arduino Uno 固件 (firmware/sucker/sucker.ino)
      │  舵机式 PWM 信号
      ▼
A0 = 吸盘（气泵）      A2 = 电磁阀
```

---

## 一、接线

| Arduino | 接到 | 说明 |
|---|---|---|
| **A0**（数字 14） | 吸盘 / 气泵 模块信号线 | `180` = 吸，`0` = 停 |
| **A2**（数字 16） | 电磁阀 模块信号线 | `180` = 进气放料，`0` = 关 |
| **GND** | 外部电源负极 | **必须共地** |

> **供电警告**：气泵和电磁阀的工作电流通常在 300 mA ~ 1 A，**绝对不要从 Arduino 的 5V 引脚取电**，
> 否则会烧稳压器或导致开发板不断重启。请用独立电源供电，只把信号线和 GND 接到 Arduino。
>
> 为什么用 A0/A2 而不是数字口？Uno 上 A0/A2 同时就是数字引脚 14/16，可以正常输出舵机信号。
> 厂家参考代码用的是引脚 8（电磁阀）和 9（气泵），本固件按你的实际接线改成了 A0/A2，并做了对调。

### 控制原理

厂家模块接收的是**舵机式 PWM 信号**，不是简单的高低电平，所以固件用 `Servo` 库输出：
`write(180)` 打开，`write(0)` 关闭。这与厂家参考代码完全一致。

如果实测发现模块其实是被当作「两线通断」控制的（比如继电器/MOS 模块），
在网页「参数设置 → 输出模式」里切成 **digital** 即可，不需要改线或重新烧录。

## 二、首次安装

```bash
./scripts/setup.sh      # 下载 AVR 工具链 + Servo 库（约 250MB，只需跑一次）
```

工具链会装在项目内的 `.arduino15/`，**不会污染** `~/Library/Arduino15`，也不会影响你已装的 Arduino IDE。

## 三、烧录固件

```bash
./scripts/flash.sh                          # 默认上传到 /dev/cu.wchusbserial1110
./scripts/flash.sh /dev/cu.usbmodem14201    # 或指定串口
```

## 四、启动服务

```bash
./scripts/run.sh --open      # 启动并自动打开浏览器
```

然后访问 **http://127.0.0.1:8787** 。`Ctrl+C` 停止（停止时会自动关闭两路输出）。

常用参数：

```bash
./scripts/run.sh --list                     # 列出可用串口
./scripts/run.sh --port /dev/cu.xxx         # 手动指定串口
./scripts/run.sh --http-port 8899           # 换端口
```

## 五、网页怎么用

| 操作 | 说明 | 快捷键 |
|---|---|---|
| **吸取** | 打开吸盘（气泵）吸住物体 | `空格` |
| **放下** | 先停泵，再开电磁阀脉冲进气放料 | `回车` |
| **急停** | 两路立刻全关 | `Esc` |

- 顶部三个指示灯：**服务**（网页与后端连通）、**串口**（端口已打开）、**设备**（开发板握手成功）
- 中间两盏状态灯实时显示吸盘和电磁阀的真实通断状态
- 参数改动后 0.45 秒自动下发到设备并保存，下次启动仍然生效

### 参数

| 参数 | 默认 | 含义 |
|---|---|---|
| 吸取保持时长 | `0` | **0 = 一直吸住，直到点「放下」**；填正数则到点自动停 |
| 放气脉冲时长 | `800` | 电磁阀进气多久后自动关闭，与厂家参考代码一致 |
| 看门狗超时 | `15000` | 超过这么久没收到命令就自动全关；`0` = 关闭 |
| 输出模式 | `servo` | `servo` = 舵机信号（厂家模块）；`digital` = 普通高低电平 |

## 六、安全机制

1. **上电即关闭**：固件启动第一时间把两路置为「关」，不会一插电就吸住。
2. **看门狗**：桥接服务每 1.5 秒发一次心跳。如果服务崩溃、电脑休眠或 USB 掉线，
   开发板会在看门狗超时后**自动关闭两路输出**，避免气泵一直空转烧毁。
   已实测：用 `kill -9` 硬杀服务进程后，气泵在超时后自动停止。
   为防止误触发，看门狗有 **6000 ms 安全下限**（必须显著大于心跳间隔），设置更小的值会被自动抬高并提示。
3. **退出即断电**：`Ctrl+C` 停止服务时会先发送 `STOP`。
4. **仅本机可访问**：服务只绑定 `127.0.0.1`，局域网内其他设备访问不到。

> 注意：页面关闭但服务仍在运行时，吸盘**保持当前状态**（不会自动放下）。
> 这是有意设计——避免误关网页就掉件。要立即松开请点「急停」。

## 七、串口协议（可直接用串口工具调试）

115200 8N1，命令以 `\n` 结尾，不区分大小写。设备回 JSON。

| 命令 | 作用 |
|---|---|
| `PICK [ms]` | 吸盘开；`ms > 0` 到点自动关，缺省用 `pick_ms` |
| `DROP [ms]` | 吸盘关 + 电磁阀脉冲进气放料 |
| `STOP` | 两路全关 |
| `SET pick_ms N` | 吸取保持时长，`0` = 保持到 `DROP` |
| `SET drop_ms N` | 放气脉冲时长 |
| `SET watchdog N` | 看门狗超时，`0` = 关闭 |
| `MODE servo\|digital` | 切换输出模式 |
| `STATUS` | 回传一行状态 JSON |
| `PING` | 心跳，回 `PONG` |

状态变化时固件会主动上报：

```json
{"ev":"state","pump":1,"valve":0,"pick_ms":0,"drop_ms":800,"watchdog":15000,"mode":"servo","up":123456}
```

## 九、故障排查

| 现象 | 原因与处理 |
|---|---|
| 顶部「串口」灯红，提示打开失败 | Arduino IDE 的串口监视器正开着，会独占端口，先关掉它 |
| 「串口」亮但「设备」不亮 | 固件没跑起来，重新执行 `./scripts/flash.sh` |
| 找不到串口 | 换一根 USB 线（有些线只能供电不能传数据）；`./scripts/run.sh --list` 确认 |
| 点击没反应 | 看网页运行日志里的报错；确认外部电源已开、共地已接 |
| 吸盘动作方向相反 | 模块电平定义不同，把固件里的 `ANGLE_ON` / `ANGLE_OFF` 对调（0 ↔ 180）后重新烧录 |
| 舵机信号驱动无效 | 在网页把「输出模式」改成 `digital` 再试 |
| 端口号不是 wchusbserial | 用 `./scripts/run.sh --list` 查看实际端口并 `--port` 指定 |
